## On-Screen Content
- **Header**: The Hook · 04 / 81
- **Title**: Why This Course Exists
- **Lede**: Problem — "Vibe coding" — asking AI to write code without process — produces unmaintainable, untested code that breaks in production.
- **Four Pillars**:
  - 01 5-Phase Framework — Process creates reproducibility. Reproducibility creates trust.
  - 02 Extension Architecture — Skills + Hooks + MCP extend Claude's capabilities to your stack.
  - 03 Live Demonstrations — Theory without practice is entertainment, not education.
  - 04 Hands-On Learning — You build alongside. Every phase, every skill, every decision.
- **Takeaway**: → Process beats prompts. The 5-phase framework turns "vibe coding" into engineering.
