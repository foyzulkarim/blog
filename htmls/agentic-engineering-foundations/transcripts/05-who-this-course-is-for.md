# Slide 05 — Who This Course Is For

## On-Screen Content
- **Header**: The Hook · 05 / 81
- **Title**: Who This Course Is For
- **Table**:
  - Software Engineers | AI writes code but they can't maintain it. | Disciplined framework + quality gates.
  - Team Leads | Team uses AI inconsistently. | Repeatable standards + review process.
  - Senior Developers | Need the full picture, not just code generation. | Architecture + context + optimization.
  - Architects & Leads | No standards exist for AI-assisted work. | Design patterns others can follow.
- **Prerequisites**: Terminal familiarity · Git · One programming language
- **Takeaway**: → No matter your role, agentic engineering needs process + tools + practice.

## Speaker Transcript (Bengali)

একটু থামুন আর নিজেকে জিজ্ঞেস করুন — এই মুহূর্তে আপনি কোথায় দাঁড়িয়ে আছেন?

Agentic engineering কোনো senior-level exclusive skill না। এটা একটা নতুন skill — এবং সবাই প্রায় একই জায়গা থেকে শুরু করছে। কিন্তু কোথায় এটা সবচেয়ে বেশি কাজে আসে, সেটা role অনুযায়ী আলাদা।

যদি আপনি Software Engineer হন, আপনি probably code generate করছেন বোঝার গতির চেয়ে দ্রুত। এমন file আছে যেগুলো আপনি লেখেন নি, dependency আছে যেগুলো আপনি choose করেন নি, আর একটা creeping anxiety আছে যে পুরোটা পড়ে যেতে পারে। আপনি যা gain করবেন তা হলো একটা disciplined framework — প্রতিটা step-এ quality gate দিয়ে — যাতে যে code ship হয়, সেটা আপনি আসলে trust করতে পারেন।

যদি আপনি Team Lead হন, আপনার problem হলো consistency। Team-এ একজন AI দিয়ে productive কাজ করছে। বাকি তিনজন chaos তৈরি করছে। কোনো standard না। কোনো review process না। জানার কোনো উপায় না AI-generated code safe কি না merge করার জন্য। আপনি যা gain করবেন তা হলো একটা repeatable standard — একটা review process আর guardrails যেটা সবার জন্য apply হয়, শুধু যে সবচেয়ে বেশি blog post পড়েছে তার জন্য না।

যদি আপনি Senior Developer হন, আপনার full picture লাগে। Architecture decisions। Context management। Token optimization। আপনি faster coder হতে চান না — আপনি agentic architect হতে চান। এই course আপনাকে সেই patterns দেবে যেগুলো আপনাকে prompt করতে পারা একজন থেকে orchestrate করতে পারা একজনে পরিণত করে — পুরো system।

যদি আপনি Architect বা Tech Lead হন, আপনার frustration-টা আমি চিনি — এটার কোনো standard নেই। কেউ playbook লেখেনি। প্রতিটা team নিজের মতো করে করছে, আর কোনোটাই repeatable না। আপনি যা gain করবেন তা হলো একটা design pattern: একটা documented, repeatable framework যেটা অন্য engineer-রা follow করতে পারে। আপনি সেই person হবেন যে standard সেট করে।

Prerequisites নিয়ে একটু বলি — list-টা ছোট, ভয় পাওয়ার কিছু নেই। Terminal চালাতে পারলেই হবে। Git — commit, branch, merge। আর যেকোনো একটা programming language। Demo-তে আমি TypeScript ব্যবহার করছি, কিন্তু framework নিজে language-agnostic — concept সব জায়গায় transfer হয়।

আপনার role যাই হোক না কেন, একটা জিনিস সবার জন্য সমান: agentic engineering-এ process লাগে, tools লাগে, আর practice লাগে। তিনটাই। একটা বাদ দিলে বাকি দুটো কাজ করে না।

চলুন এবার জানি — agent জিনিসটা আসলে কী?
