## Speaker Transcript (Bengali)

Agentic Software Engineering — The Complete Course-এ আপনাকে স্বাগতম।

আমার নাম Foyzul Karim। আগামী কয়েক ঘণ্টায় আমরা দেখবো কীভাবে AI agent দিয়ে real software বানানো যায় — শুধু fast নয়, বরং এমনভাবে যেটা আমরা trust করতে পারবো।

সবাই এখন একটা কথায় একমত: AI coding agent-গুলো human-only development-এর চেয়ে দশ গুণ faster। এটা সত্যি। আমি নিজে measure করেছি।

কিন্তু একটা সমস্যা আছে। বেশিরভাগ মানুষ সেই speed পাচ্ছে না। কারণ তারা AI-কে ব্যবহার করছে যেভাবে একজন junior developer কাজ করে — শুধু বলছে "এটা বানাও", "ওটা ঠিক করো" — কোনো plan নেই, কোনো architecture নেই, কোনো structure নেই। AI তখন দ্রুত code লেখে ঠিকই, কিন্তু সেই code কোথায় যাচ্ছে কেউ জানে না।

Result? দুই সপ্তাহ পর codebase এমন জায়গায় পৌঁছায় যেটা কেউ বুঝতে পারে না। নতুন feature add করতে গেলে তিনটা জায়গা ভেঙে যায়। Test নেই, documentation নেই — আর AI-ও আর সাহায্য করতে পারে না, কারণ context এত বড় হয়ে গেছে যে সে নিজেই হারিয়ে গেছে। এটাই vibe coding-এর শেষ পরিণতি। Speed ছিল, কিন্তু engineering ছিল না।

এখানেই architecture আর engineering practice-এর দরকার হয়। AI আমাদের হাতকে দশ গুণ fast করে দিতে পারে — কিন্তু সেই হাত যদি সঠিক জায়গায় না লাগে, তাহলে সেই speed-ই হয়ে ওঠে সবচেয়ে বড় বিপদ।

এই course-টা তৈরি হয়েছে একটা 5-phase framework-কে কেন্দ্র করে — Requirements থেকে Architecture, Tasks, Implementation, আর Review পর্যন্ত — যেটা AI-এর raw speed-কে এমন কিছুতে পরিণত করে যেটা আমরা deploy করতে পারবো, maintain করতে পারবো, আর রাতে ঘুমাতে পারবো।

যদি আপনি vibe coding-এর ওপর ক্লান্ত হয়ে গেছেন, আর agent দিয়ে আসল engineering করতে চান — এমন software যেটা কাজ করে, যেটা টেকে — তাহলে আপনি ঠিক জায়গায় আছেন। চলুন শুরু করি।
