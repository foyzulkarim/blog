don't fight it with custom widths.

## A section heading

Headings are `##` and `###`. There is exactly one `<h1>` per page and it comes from `title`,
so never write `#` in the body.

- Bullet lists work as expected.
- `Inline code` and [links](https://example.com) are styled by the global stylesheet.

### Figures and diagrams

`<Figure>` handles the framing, the caption, and the full-bleed escape. Use `bleed` when the
content needs more room than the 68ch measure, and `scroll` for anything with fixed geometry
(diagrams) so it keeps its size on a phone instead of shrinking into illegibility.

<Figure
  bleed
  scroll
  eyebrow="Small label above the figure"
  caption="What the reader should take from it."
>
  <svg class="diagram" viewBox="0 0 880 120" role="img" aria-label="Describe the diagram in a sentence — this is what a screen reader announces.">
    {/* Use the token classes so the diagram works in dark mode:
        box--raised  box  box--emphasis   stroke  stroke--dash  arrow
        label  label--sm  eye  text--emphasis  text--warm  anchor-start
        Never hardcode a colour — #fff disappears against a dark background. */}
    <rect class="box--raised" x="20" y="30" width="160" height="56" rx="8" />
    <text class="label" x="100" y="64">A box</text>
    <rect class="box--emphasis" x="260" y="30" width="160" height="56" rx="8" />
    <text class="label text--emphasis" x="340" y="64">An emphasised box</text>
  </svg>
</Figure>

{/*
  SVG GOTCHA: keep <text> content on ONE line.
  MDX parses a wrapped child as Markdown and injects a <p>, which breaks the
  SVG and silently swallows everything after it. `npm run verify` catches this.
*/}

### Tables

Wrap wide tables so they scroll instead of squeezing, and always give a `<caption>`:

<div class="bleed">
  <div class="table-scroll" tabindex="0" role="region" aria-label="Describe the table">
    <table class="table--sticky">
      <caption>What the table measures, and when.</caption>
      <thead>
        <tr><th scope="col">Thing</th><th scope="col" class="num">Value</th></tr>
      </thead>
      <tbody>
        <tr><th scope="row">First</th><td class="num">1.9</td></tr>
      </tbody>
    </table>
  </div>
</div>
